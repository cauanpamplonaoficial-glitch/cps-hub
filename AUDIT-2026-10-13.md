# CPS Hub V2 — technical audit (2026-10-13)

## Scope reviewed
- `package.json`, `next.config.ts`, `app/layout.tsx`, `app/page.tsx`, `app/globals.css`, GitHub Pages workflow and deployment notes.
- This is a source-level review; it is not a penetration test or a full runtime test.

## Findings
1. **Critical dependency maintenance required:** the repository used Next.js 15.5.4 and React 19.1.1. Next.js' official December 11, 2025 security notice identifies fixes later than these versions for App Router security issues. The dependency versions have been updated to Next.js 15.5.27 and React/React DOM 19.1.2. Confirm with CI and a dependency audit before treating this as resolved. Sources: https://nextjs.org/blog/security-update-2025-12-11 and https://nextjs-changelog.vercel.app/
2. **No lockfile present:** builds use `npm install` without a committed `package-lock.json`, so dependency resolution is not reproducible. Add and commit a lockfile after running npm install and verifying the build.
3. **Dashboard is demonstrative:** `app/page.tsx` uses hardcoded `demoSales`; create buttons notify that the CRUD is planned; modules are visual placeholders. Do not use it to record real sales or inventory.
4. **No application backend/auth:** no Supabase client, login, session protection, or database connection is present in the reviewed app files.
5. **CSV export:** export is generated in the browser from the filtered demonstration array; it is not a database export.
6. **GitHub Pages is static hosting:** suitable for this prototype only. When authentication and database-backed modules are implemented, confirm the architecture supports the required runtime or move the app to a host that supports the chosen server-side features.
7. **Data isolation:** the known older Supabase project is inactive and is not being used. Do not restore, migrate, or modify it as part of this test setup without explicit approval.

## Required before connecting a test project
- Verify CI build and deploy after dependency update.
- Generate and commit `package-lock.json`; run dependency audit.
- Review the test migration for cross-table ownership constraints, inventory transaction semantics, and owner isolation; run Supabase security advisors after applying it to a new test project.
- Create a separate test project only after organization and estimated costs are confirmed.
- Keep all service-role secrets server-side; never place them in browser code.
